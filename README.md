# 스펙박스 (SpecBox)

> 공고를 고르면, 필요한 서류가 따라옵니다.

취업 준비생에게 전공·희망 직무에 맞는 채용 공고를 추천하고, 공고의 제출서류를 내 서류 금고와 대조해 준비할 서류와 마감 일정을 알려 주는 웹 서비스입니다.
전북대학교 클라우드컴퓨팅응용 수업의 비영리 학생 프로젝트입니다.

## 주요 기능 (MVP)
- 고용24 채용정보 수집과 맞춤 공고 추천
- 자격요건·우대사항 키워드와 내 프로필 일치 표시
- 서류 금고 (증명서, 어학 성적, 자격증, 포트폴리오)
- 제출서류 체크리스트와 마감·재발급 알림

## 인프라
AWS 멀티 VPC(Service, Processing, Data) + VPC Peering, ALB, Auto Scaling, SQS, RDS, S3, SNS

## 팀
최준혁, 이대복
